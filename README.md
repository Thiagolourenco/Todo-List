## App Todo List #1


### Description

This is App, the user can add new item in a list. This list the user can, delete, move positions and add new item. 
The objective this app, it was to test improve my skills in Swift/SwiffUI

### What did you use ? 

* I used MVVM to separate responsabilities
* UsersDefaults to saved items in memory phone
* Codable to worked JSON in Swift
